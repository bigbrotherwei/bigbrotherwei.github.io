分域说明

  • TS：事务版本、冲突检查、提交编排与关键元数据视图。
  • Log System：mutation durability、tagged log 与恢复状态流。
  • Storage Servers：最终 KV/MVCC 状态、System Keyspace、直接读。
  • Control Plane：招募、恢复、数据分布、流控，不作为每次 KV 请求的固定中间层。

两个关键边界

1. TLog durable：事务提交 durability boundary。SS apply 不在 commit latency 的必经链路里。

2. Client direct read：正常读路径不经 Commit Proxy；只有 location cache miss/stale 时才查询 CP。

该图用于解释 FoundationDB 核心逻辑架构与交互边界；具体版本在 version-vector、多地域、角色命名等方面可能有实现差异。
