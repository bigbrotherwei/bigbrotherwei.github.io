# 第十四阶段：实用工具扩充与分类浏览

## 目标与边界

在现有 Astro 静态博客中增加五个可独立使用的工具：进制转换、SHA 摘要、随机密码、二维码生成、原创的 16 型性格偏好探索。工具目录默认按分类分组，分类仍只存在于同一个目录页，不创建分类详情路由。所有输入和运算留在浏览器，不新增账号、上传接口、运行时后端或第三方统计。

保留现有工具 URL、搜索、分类筛选、明暗主题和每页独立的手绘夜景背景。参考外部工具的功能需求，不复制其代码、题目、说明文字或视觉素材。

## 方案选择

1. **推荐：现有工具注册表 + 五个独立页 + 同页分类分组。** 延续当前 `ToolLayout`、分类和构建校验；目录默认显示全部分类，搜索时隐藏无结果的分组。实现范围清晰，静态部署不变。
2. 每类工具建立单独页面。目录与路由数量增加，与用户要求不符，放弃。
3. 嵌入外站工具或在线测评。难以保证可用性、隐私和统一风格，也无法控制题目授权，放弃。

## 工具目录

- `全部`是初始选中状态。分类按注册表顺序成为目录页的小标题，标题下仅列该类工具卡片；现有搜索框和分类按钮保留在顶部。卡片继续链接独立工具页，而不是分类页。
- 搜索与分类筛选可叠加。隐藏无匹配卡片及空分组，更新可见数量和空状态；清空搜索恢复当前分类，切回`全部`恢复所有分组。无 JavaScript 时按分类完整展示。
- 新增`趣味探索`分类容纳性格偏好测试。旧工具仍保持原有分类和 URL。手机端标题、筛选、卡片不产生页面级横向滚动。

## 五个工具

### 进制转换

支持 2、8、10、16 进制常用选项和 2–36 的整数进制转换；用 `BigInt` 保留大整数精度。明确不支持小数与科学记数法。校验源进制内非法字符、空输入和超过 256 位的输入；显示目标结果，支持交换进制与复制。不能把 Base64 当作 64 进制。

### SHA 摘要

使用浏览器 Web Crypto 对文本或一个本地文件计算 SHA-256、SHA-384、SHA-512，输出十六进制摘要并支持复制。文件只在本地读取，不发送到服务器；单文件上限 32 MiB，超限或浏览器不支持时给出错误。`SHA`是摘要而非可逆“加密”，页面不提供 MD5 作为安全校验选项。

### 随机密码

使用 `crypto.getRandomValues` 生成，不使用 `Math.random`。允许设置 8–64 位长度及大小写、数字、符号字符组；至少选择一组，生成结果包含每个已选组的字符。可生成、复制、重置；不保存历史、不写入 URL 或本地存储，不宣称密码强度评级。

### 二维码生成

文字或链接在浏览器本地编码，选择常用尺寸和纠错级别，预览后下载 PNG。使用成熟的二维码编码库，不手写编码算法；输入上限 1000 UTF-8 字节，对空输入、容量不足和下载失败给出反馈。页面不调用外站二维码 API，也不将输入插入可执行 HTML。

### 16 型性格偏好探索

- 采用 32 道原创的中文情境题，四个偏好维度各 8 道，题目方向交错，避免单向同意偏差。五档回答从“更接近左侧”到“更接近右侧”，允许返回修改，必须答完才显示结果。题目、说明和类型解读不照搬官方或其它站点材料。
- 五档回答按 -2 至 +2 计分，题目方向交错并归一到各维两端；四维各自的总分范围为 -16 至 +16。结果展示两端相对倾向和各维解释：绝对值不超过 2 时标记“倾向不明显”，零分的维度标记“未定”，不强行生成唯一四字母组合；其它情况给出最接近的组合并标出弱倾向。所有结果由实际回答确定，不使用随机结果。
- 页面标题和主要文案使用“16 型性格偏好探索”，明确这是原创、非官方的自我探索工具，不是官方 MBTI 测评、心理诊断或招聘筛选依据。不使用官方题目、类型名称文案、标志或授权暗示。
- 答案仅保存在当前页面内存，不上传、不写入 URL、`localStorage` 或分析事件。刷新会重新开始；界面说明这一点。结果不自动公开分享。
- 题目支持键盘操作，进度和校验反馈可被辅助技术读取；结果图表不能仅靠颜色传达含义。手机端一次呈现一道题，减少动态效果时不播放题目切换动画。

## 视觉与背景

五个独立工具页各配置一对原创的桌面/手机 WebP 背景，延续本站的夜间手绘乡村场景并加入与工具用途有关的轻微场景线索。背景不复制游戏或外站素材；重点保证正文、输入框和结果在明暗主题下可读。遵守现有素材体积、响应式预加载和构建校验，不因页面数量增加而让目录页预加载所有工具背景。

## 实现边界与验收

- 扩展 `src/data/tools.ts`、背景注册表、五个工具路由及对应的纯逻辑模块；目录页重排为按分类分组。更新工具契约、生产产物、搜索与素材验证中现有的硬编码工具清单。工具页沿用已有的状态提示、复制反馈和隐私说明模式。
- 单元测试覆盖数值边界、摘要已知向量、密码字符组/随机源、二维码空值与超限、问卷完整性/反向题/边界分数，以及目录搜索与分组同时工作的行为。构建验证所有工具路由、分类、背景与 Pagefind 索引。
- 浏览器抽查五个新页和工具目录的桌面/手机、明暗主题、键盘焦点与错误状态；检查文件输入、下载与重置。运行完整 `npm run build` 后提交 PR。
- 本批不做官方授权测评、结果账户/排行榜、社交分享、服务端保存、密码管理器、二维码扫描、超大文件流式摘要或工具分类详情页。
