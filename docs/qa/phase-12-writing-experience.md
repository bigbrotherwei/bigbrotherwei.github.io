# 阶段十二：文章创作与阅读体验验收记录

## 范围

- 原有 `.md` 文章保持不变；`.mdx` 文章使用相同的文章集合、frontmatter、路由、搜索与 RSS 流程。
- 可选的提示框、图片画廊、折叠内容，以及文章图片查看和代码复制。
- 发布前检查文章元数据、专题顺序、图片替代文本及本地资源路径。
- Markdown 预览工具扩大工作区；桌面端等高双栏按滚动比例联动，窄屏改为上下排列。
